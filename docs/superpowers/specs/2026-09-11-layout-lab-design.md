# 页面布局课程教学网站设计

用户已批准多级路由和八章课程，要求计划后直接实施。
采用 React、React Router HashRouter、Ant Design、Lucide。纯静态网站，无后台密钥。
首页课程目录；章节概览、基本知识、典型代码、实时演示独立嵌套路由；练习列表和详情独立路由；未知地址有返回入口。不采用固定左中右三栏。
八章为盒模型、文档流、定位、Flex、Grid、响应式、页面结构、综合实战。每章至少三个知识点、完整示例、特有实验参数、自测题。
实验采用禁止脚本的 sandbox iframe，参数实时生成 CSS；支持 HTML/CSS 编辑、重置、预览宽度、复制下载。进度 localStorage 保存，损坏或禁用时回退。
白底墨色文字、绿色操作、蓝橙紫粉章节色。无框纵向内容，大面积实验预览。支持手机和桌面。
GitHub Actions 发布 Pages；PowerShell 脚本使用 gh 建仓推送和配置 Pages。用户手动执行才公开发布，本轮不自动创建远端仓库。
